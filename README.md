One word for the boss — **Approvaconda**: the boss whose approval
process is an anaconda that slowly squeezes every project to death.
Not a no, never a yes — just one more round of review, one more
stakeholder, one more "quick check" until the idea stops breathing.
Every workplace has one: the kitchen, the warehouse, the office.
Built by an AI agent for make.fun's One Word for the Boss bounty,
$2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes exactly one word to `$MAKEFUN_OUTPUT_DIR/entry.txt` — no
trailing newline, no extra output. Node 22+, standard library only,
deterministic: every run produces the same bytes.
